## 1. 定位：配置页，不是功能页

MCP 接入的用户旅程是「配置一次，长期在别处使用」。因此：

**它不进主导航。** 放在 `设置 → MCP 接入`，与模型配置同级。放进主导航会让用户以为这是一个日常要来的页面。

**它的主角是「复制」，不是「浏览」。** 页面上的每个设计决定都服务于一件事：让用户尽快把配置贴到 Claude Code 或 Cursor 里，然后离开。

**它必须能自证可用。** 配好之后用户看不到任何反馈，会怀疑是不是没生效。因此页面要提供「测试连接」与最近调用记录，让「它真的在被使用」这件事可见。

---

## 2. 页面结构

```text
/settings/mcp
├─ 令牌列表（默认视图）
├─ 创建令牌（向导，三步）
└─ 调用日志（Tab 切换）
```

左栏仍是设置的分组导航，主内容最大 720。**不设右栏**——这一页没有需要常驻对照的信息。

### 2.1 令牌列表

**顶部说明条**（首次进入且无令牌时）：一句话说清 MCP 是什么、能做什么，附「查看支持的工具」的折叠。

**表格列**：名称、作用域摘要、最近使用、今日调用、状态、操作。

作用域摘要显示为「全部文档 · 5 个工具」或「标签：MCP、Agent · 5 个工具」，**不展开长列表**，点击行进入详情。

状态三种：生效中、已过期、已吊销。已吊销的行保留但降低透明度，**不删除**——审计需要。

行操作：复制令牌 ID（不是令牌本身）、编辑作用域、吊销。**没有「查看令牌」**，因为明文只存在过一次。

### 2.2 创建令牌向导

三步，右侧常驻「配置预览」卡片，随步骤实时更新。

**第一步：名称与范围。**

- 名称必填，建议写用途（如「Claude Code 本机」），因为日后要靠名字辨认。
- 范围三选一：全部文档 / 按标签 / 指定文档。
- 选「按标签」时展示标签选择器（可搜索、多选）；选「指定文档」时展示文档搜索器。
- 选中范围后，预览卡片显示「约 82 份文档可被访问」——**给数量，不给百分比**，数量更可判断。

**第二步：工具。**

六个工具，五个只读默认开启，提案工具默认关闭并附一行说明「只创建待审核提案，不会直接修改知识」。每个工具显示：名称、一句用途、单次返回体积上限。

**不允许「全选」按钮。** 六个工具不多，全选只会让人跳过思考；逐个确认是有意的摩擦。

**第三步：限制与有效期。**

每日调用上限（默认 500）、QPS（默认 5）、有效期（30 / 90 / 365 天 / 永不过期）。

「永不过期」放在最后并标注风险色文字：「长期有效的令牌一旦泄露，影响持续到手动吊销」。

底部按钮：上一步 / 创建令牌。

### 2.3 一次性密钥展示

创建成功后**整页切换**为密钥展示态，而不是弹窗。理由：弹窗容易被误关，而这是唯一一次能看到明文的机会。

内容自上而下：

1. 标题「令牌已创建」，副标题「这是唯一一次显示完整令牌」。
2. 令牌明文，等宽 14px，`--surface-sunken` 底，右侧「复制」按钮；点击后按钮变为「已复制」并保持 2 秒。
3. 一个**必须勾选**的复选框：「我已保存到安全位置，知道关闭后无法再次查看」。未勾选时，「完成」按钮禁用。
4. 底部「完成」与「复制接入片段」。

**不做自动关闭，不做倒计时。** 倒计时会制造焦虑并导致误操作。

**离开页面时的拦截。** 若未勾选就尝试离开，弹出确认：「令牌只显示一次，离开后将无法查看。确定离开？」。

### 2.4 接入片段

一个抽屉或内嵌区块，三个 Tab：Claude Code、Cursor、通用 JSON。

片段内容为完整可复制的配置，其中令牌位置显示为 `kos_xxxxxxxx`（**用占位符，不回填真实令牌**）。

原因：如果把真实令牌填进片段，用户复制到聊天窗口或 issue 里就会泄露。占位符强制他回去看自己的密钥。

每个 Tab 底部一句：「把 `kos_xxxxxxxx` 替换为你刚创建的令牌」。

**验证提示。** 片段下方有一行「配置后重启客户端，然后让 Agent 试一次『搜索我的知识库里的 RRF』」。

### 2.5 调用日志

Tab 切换，表格列：时间、令牌、工具、耗时、返回条数、状态。

**不显示查询词与返回内容**，只显示条数。需要排查时点击行展开，看到脱敏后的参数摘要。

顶部筛选：时间范围、令牌、工具、状态。

顶部指标条：今日调用 / 失败率 / 平均延迟 / 被限流次数。四项都来自审计表。

**空状态**：「还没有调用记录。配置完成后，Agent 的每次调用会出现在这里」+ 「复制接入片段」按钮。

### 2.6 测试连接

列表页顶部「测试连接」按钮。点击后：

- 校验令牌有效性（用列表里选中的令牌，或最近创建的）。
- 发起一次内部的 `search_knowledge` 探针查询。
- 结果显示：成功（绿色 + 延迟 + 返回条数）或失败（红色 + 可读原因）。

**测试不消耗用户额度**，也不写入调用日志（标记为探针）。

## 3. 状态与文案

| 场景 | 文案 |
| --- | --- |
| 无令牌 | 「还没有接入令牌。创建一个，让 Claude Code 或 Cursor 读取你的知识库」 |
| 令牌已过期 | 「已于 2026-09-30 过期，无法再调用」 |
| 已吊销 | 「已于 2026-10-12 吊销，历史调用记录保留」 |
| 作用域为空 | 「所选标签下没有文档，该令牌将无法检索到任何内容」——**创建前就要告诉用户** |
| 令牌创建失败 | 「创建失败，请重试」+ 错误码，不显示内部堆栈 |
| 调用被限流 | 日志中状态显示「限流」，展开显示恢复时间 |
| 探针失败 | 「连接失败：令牌无效或服务未启动」+ 「查看排查步骤」 |

**「作用域为空」必须前置。** 用户选了空标签，创建出来的令牌就是废的，而这个错误在创建时就能发现，不该等到第一次调用才暴露。

## 4. 深色主题适配

| 元素 | 深色处理 |
| --- | --- |
| 令牌明文块 | `--surface-sunken` 底 + `--line-control` 描边，确保等宽字符清晰 |
| 一次性警告 | `--state-warn-bg` 底 + `--state-warn-border`，不用红色——这是「注意」不是「危险」 |
| 复制按钮成功态 | `--success` 文字 + `--state-success-bg` 底 |
| 日志表格 | 表头 `--surface-sunken`，行 hover 同色；状态徽标用低饱和三件套 |
| 已吊销行 | 整体 `--text-disabled`，但保留边框，避免像「加载中」 |

**令牌明文不要用高对比白字。** 长串等宽字符在纯白下会刺眼，用 `--text-primary`（深色下是暖白）即可。

## 5. 响应式

| 断点 | 变化 |
| --- | --- |
| ≥1024 | 向导右侧预览常驻 |
| 768–1023 | 预览折叠为顶部摘要条 |
| ≤767 | 向导改为全屏单列；一次性密钥块自动换行（不允许横向滚动）；日志表格转卡片 |

**令牌明文在窄屏必须可换行。** 32 字节的随机串在 390px 下会溢出，`word-break: break-all` 是必做项，否则用户无法完整复制。

## 6. 验收

- DV3-1：令牌明文只在创建成功后出现一次，刷新或离开后无法再次查看。
- DV3-2：未勾选「已保存」时无法完成，离开页面有拦截确认。
- DV3-3：接入片段中使用占位符，不回填真实令牌。
- DV3-4：作用域选择为空时，创建前就给出提示。
- DV3-5：调用日志不显示返回正文，展开后参数已脱敏。
- DV3-6：已吊销令牌的记录保留且可筛选，不显示为「加载中」。
- DV3-7：390 宽下令牌明文可完整显示与复制，无横向滚动。
- DV3-8：测试连接不写入调用日志、不消耗额度。
- DV3-9：深色主题下一次性密钥块与警告条对比度达标，无发灰。

## 7. 与 PRD 的对应

| PRD 要求 | 设计落点 |
| --- | --- |
| 令牌只存哈希、显示一次 | 2.3 一次性密钥展示 |
| 作用域四维 | 2.2 三步向导 |
| 审计不记录正文 | 2.5 日志只显示条数 |
| 吊销即时生效 | 列表行操作，无撤销延时 |
| 接入片段 | 2.4 占位符 + 三个客户端 Tab |
| 可自证可用 | 2.6 测试连接 + 调用日志 |
