## 1. 两套局部语言

前三个版本统一用「纸 + 索引」。V2 引入两个新东西，它们需要各自的视觉语法，但不能破坏整体：

**图谱是「地图」，不是「仪表盘」。** 地图的价值在于方位感与可缩放，不在于数据密度。所以画布要安静：节点少、边细、标签克制、背景近于纸色。**不做发光节点、不做渐变连线、不做力导向的持续抖动。**

**执行回放是「时间线」，不是「日志表格」。** 用户要回答的是「它为什么这么做」，所以顺序和因果比字段完整更重要。时间线纵向排列，每一步先给结论再给细节。

两者的共同约束：**任何新增视觉都必须能回答「它在告诉我什么」。** 图谱里的一条边如果只表示「这两个词在同一段出现过」，它就不该被画出来。

## 2. 图谱页

### 2.1 布局

全屏画布 + 左上浮动工具条 + 右侧详情抽屉（360，默认收起）+ 底部图例条。

**为什么不用三栏骨架。** 图谱需要横向空间；再塞一个固定侧栏会让画布只剩 700px，两跳就铺不开。因此侧栏改为抽屉，按需展开。

### 2.2 画布

| 元素 | 规格 |
| --- | --- |
| 背景 | `--surface-canvas`，叠加 24px 点阵（`--line-subtle`，透明度 40%），提供空间参照 |
| 节点 | 圆形，直径 28（焦点 40），填充 `--surface-sunken`，描边 `--line-control` 1.5px |
| 节点选中 | 填充 `--accent-weak`，描边 `--accent` 2px，外圈 6px 光晕（`--accent` 12% 透明） |
| 节点标签 | 12px sans，位于节点下方 6px；节点数 > 150 时仅悬停显示 |
| 边 | 1px 实线 `--line-control`，箭头 6px |
| 边（待定） | 1px 虚线 `--text-disabled` |
| 边（冲突） | 1.5px 双线 `--danger` |
| 边标签 | 默认隐藏，悬停显示关系类型（mono 11px） |

**节点类型靠图标，不靠颜色。** 圆内放一个 14px 线性图标：Concept 用圆点、Technology 用方块、Project 用文件夹、Agent 用机器人轮廓、Protocol 用连线。**五种类型五种颜色会让图变成调色盘**，反而看不出重点；颜色只留给「选中」和「冲突」两个状态。

### 2.3 交互

**默认视图。** 无焦点时显示「度数最高的 20 个节点」，画布中央上方有一行说明：「显示高频概念，搜索或点击节点查看关系」。**不能让用户以为这就是全图。**

**展开。** 点击节点 → 展开一跳 → 新节点从点击位置向外扩散 180ms，已有节点轻微退让（不超过 12px）。**不做持续力导向抖动**，布局计算一次后固定。

**搜索。** 左上搜索框，输入实时匹配实体名，Enter 后画布平滑平移并高亮，不清空已有视图。

**面包屑。** 展开多跳后，顶部显示路径 `Qdrant → 稀疏向量 → 混合检索`，点击任一段回退到该层。

**双击空白** 回到默认视图。

### 2.4 规模与聚合

节点数 > 400 时，画面切换为按类型聚合的簇：五个大圆，标注类型与节点数，点击展开该类型的前 50 个高频节点。

顶部出现提示条：「当前视图已聚合，展开可能较慢」，附「只看选中节点」开关。

### 2.5 右侧抽屉

三个 Tab：

- **详情**：名称、类型、别名、提及次数、置信度、首次出现时间。
- **关系**：出边与入边列表，每条含关系类型、对端节点、证据数。
- **来源**：全部证据块，点击定位原文并高亮实体出现的位置。

### 2.6 状态

| 状态 | 表现 |
| --- | --- |
| 图谱为空 | 「还没有足够的关系」+ 说明需要 V1.5 抽取完成 + 当前实体数/关系数 |
| 节点无邻居 | 画布只显示该节点 + 一行「该概念暂未建立关系」 |
| 加载 | 画布中央骨架圆环，不阻塞工具条 |
| 聚合中 | 顶部提示 + 进度条 |
| 渲染失败 | 画布区域显示错误 + 「切换到列表视图」的退路 |

**必须有列表视图退路。** 图渲染失败或性能不足时，用户仍应能通过列表浏览实体与关系。

### 2.7 3D 视图（V2.1）

**3D 是桌面默认视图，不是替代品。** 工具条提供「3D / 平面 / 列表」三态：≥1024px 且 WebGL 可用时默认 3D；768–1023px 默认平面；≤767px 默认列表。用户显式选择写入 `localStorage`，刷新后保持；WebGL 不可用或上下文丢失时自动回落平面并提示。

**画布与相机。** 背景仍为 `--surface-canvas`，允许叠加 24px 点阵。左键拖拽旋转、滚轮缩放、右键/双指平移；「重置视图」回到默认机位。相机操作不得触发选中。

**节点与标签。** 几何体区分类型：concept 球体、technology 立方体、project 棱柱、agent 八面体、protocol 四面体；填充使用 `--surface-sunken`，选中用 `--accent`，冲突用 `--danger`。标签使用 SpriteText，≤150 节点全部显示；151–400 仅选中/邻居/hover；>400 聚合。

**边。** 事实实线、待定虚线、冲突红色加粗；箭头表示方向；hover 显示关系类型。3D 中不做双线（双线保留给 2D）。

**交互。** 点击节点选中并展开一跳，打开右侧抽屉；重复点击不重复请求。悬停高亮直接邻居。搜索选中实体后相机飞到目标并高亮，不清空已有视图。双击节点聚焦并展开；双击空白重置。

**冻结。** 布局只做一次收敛（`warmupTicks=40`、`cooldownTicks=120`），`onEngineStop` 后停止渲染循环；**不出现持续抖动、发光、Bloom、渐变连线或粒子流**。

**降级状态。**

| 状态 | 表现 |
| --- | --- |
| WebGL 不可用 | 1s 内切平面 + 「当前设备不支持 3D，已切换到平面视图」 |
| 上下文丢失 | 同上，保留已加载数据 |
| 首帧 >4s 或 5s 平均 <20fps | 提示「3D 视图可能较慢，可切到平面视图」+ 一键切换 |
| >400 节点 | 按类型聚合卡片；3D 按钮禁用并说明 |

**键盘与屏幕阅读器。** 3D/平面模式下额外渲染一个 `sr-only` 的「图谱节点列表」，按钮与画布共享选中/展开动作；`Tab` 进入，`Enter` 展开，`Esc` 关闭抽屉。

## 3. 问答页的关系路径

V1 的证据面板有三个 Tab（证据块、检索轨迹、原文）。V2 增加第四个「关系路径」，**只在本次检索走过图谱时出现**。

### 3.1 呈现

一条路径一行，横向链式：

```text
Qdrant  —USES→  稀疏向量  —PART_OF→  混合检索
        0.92            0.78
```

每段可点击，展开该关系的证据块。路径下方显示得分构成：置信度乘积 0.72 × 来源质量 0.88 × 弱关系惩罚 0.9 = 0.57。

**得分要展示，但不做进度条。** 进度条会让人以为这是「正确率」，而它只是一个排序依据。

### 3.2 与证据的关系

关系路径不是证据，是**索引**。点击路径里的任一关系，右栏切到「证据块」Tab 并定位到对应块。**不允许从路径直接生成结论**，界面上也不给「据此回答」这类按钮。

## 4. Agent Studio

### 4.1 列表页

左栏 Agent 列表（280）+ 主内容卡片网格。

每张卡：名称、描述一句、最近一次执行的状态与时间、本月消耗。**没有「新建 Agent」的大按钮**，用列表底部一行「+ 新建 Agent」——这个功能低频，不该占据首屏。

空状态：说明 Agent 与普通问答的区别（有工具、多步、可回放），并提供「用示例创建一个」的入口。

### 4.2 配置页

左栏列表 + 主内容表单（最大 720）+ 右侧「最近执行」摘要（320）。

表单分四段：

**基本信息**：名称、描述。

**模型与提示词**：模型选择、温度滑块、System Prompt（多行，带 token 计数）。

**工具**：六个开关，每个开关右侧一行说明该工具做什么、是否需要额外生成成本。**写入类工具不出现**，不是灰掉，是不存在。

**限制**：步数上限（默认 8，最大 12）、单次 token 预算、单日额度。

保存时若改了提示词或工具，生成新版本并提示「已生成 v3，历史执行仍按旧版本回放」。

### 4.3 执行详情（回放）

顶部摘要条：状态、总步数、总耗时、总 token、终止原因。

主体是**纵向时间线**，每步一个节点：

| 步骤类型 | 呈现 |
| --- | --- |
| 思考 | 浅灰卡片，显示模型输出摘要（3 行截断），点击展开全文 |
| 工具调用 | 卡片头显示工具名（mono）+ 状态徽标，卡片内分「参数」「返回摘要」两栏 |
| 输出 | 高亮卡片，`--accent-weak` 底，显示最终回答 |
| 终止 | 红色节点，显示原因（步数上限 / 预算耗尽 / 连续失败） |

**工具调用的参数默认脱敏展示**（`apiKey: "sk-••••4f2a"`），只有结构字段可见。

**回放控制。** 顶部有「上一步 / 下一步」与一个进度条，逐步高亮时间线；**不做自动播放动画**——用户是来排查的，不是来看演示的。

### 4.4 成本提示

触发执行前，如果预估成本超过近期中位数 2 倍，弹出确认：「本次执行预计消耗约 18k token，高于近期平均（7k）。继续？」

**提示的是数量级，不是精确值。** 精确到个位的预估既不准也不可信。

### 4.5 状态与文案

| 场景 | 文案 |
| --- | --- |
| 步数达上限 | 「执行在第 12 步终止：达到步数上限」 |
| 预算耗尽 | 「执行终止：本次预算已用完」 |
| 工具连续失败 | 「执行终止：工具 search_knowledge 连续 3 次失败」 |
| 单日额度用尽 | 「今日 Agent 额度已用完，明日 00:00 恢复」 |
| 工具参数校验失败 | 「工具参数不合法，已返回给模型修正」（在时间线中以警告态显示） |
| 记录不可编辑 | 编辑入口不出现；删除需二次确认 |

## 5. 深色主题适配

| 元素 | 深色处理 |
| --- | --- |
| 画布点阵 | 透明度降到 25%，否则亮点会像噪点 |
| 节点填充 | `--surface-sunken`（比画布亮），描边 `--line-control` |
| 节点选中光晕 | `--accent` 20%，范围 8px（深色下需要更明显） |
| 边 | `--line-control`，对比度已满足 3:1 |
| 冲突双线 | `--danger`，在深色下已提亮 |
| 聚合簇 | 填充 `--surface-sunken`，标签 `--text-secondary` |
| 执行时间线 | 连接线 `--line`，节点圆点用状态色 |

**深色下不要给节点加投影。** 暗背景上的阴影只会让节点边缘发脏。

## 6. 响应式

| 断点 | 图谱 | Agent |
| --- | --- | --- |
| ≥1280 | **默认 3D** 画布 + 抽屉 | 三栏 |
| 1024–1279 | **默认 3D** 画布 + 抽屉（默认收起） | 两栏，右侧摘要折叠为卡片 |
| 768–1023 | **默认平面** 画布占满，工具条收纳为图标 | 单栏，列表变下拉 |
| ≤767 | 抽屉全屏；**默认列表视图** | 单栏，时间线横向滚动改为纵向 |

**移动端默认用列表视图看图谱。** 350px 宽的画布上两跳就挤成一团，强行给图不如给列表。

## 7. 验收

- DV2-1：默认视图明确标注「高频概念，非全图」，用户不会误认为这是全部数据。
- DV2-2：节点类型在去除颜色后仍可由图标区分；边类型可由线型区分。
- DV2-3：节点数 > 400 时自动聚合，并出现提示条与列表退路。
- DV2-4：关系路径只在走过图谱时出现，未走时不显示空 Tab。
- DV2-5：点击路径中的关系，右栏定位到对应证据块。
- DV2-6：执行详情的时间线可用键盘逐步回放，参数已脱敏。
- DV2-7：工具参数校验失败在时间线中以警告态呈现，不显示为「执行失败」。
- DV2-8：预估成本超阈值时弹出确认，文案给数量级而非精确值。
- DV2-9：390 宽下图谱默认列表视图，无横向滚动。
- DV2-10：深色主题下图谱画布、节点、边、冲突线均清晰可辨，无发脏边缘。

## 8. 与 PRD 的对应

| PRD 要求 | 设计落点 |
| --- | --- |
| 默认两跳、按需展开 | 2.3 交互 |
| 400 节点聚合 | 2.4 规模与聚合 |
| 路径可解释 | 3.1 得分构成 + 证据串联 |
| 图谱结果回到块 | 3.2 禁止从路径直接生成结论 |
| 步数/预算终止 | 4.3 终止节点 + 4.5 文案 |
| 参数脱敏 | 4.3 工具调用卡片 |
| 记录可回放不可编辑 | 4.3 回放控制 + 不出现编辑入口 |
| 无写入工具 | 4.2 工具区不出现，而非置灰 |
